# Images

Add your own photos here. The filenames are referenced by the top-level
README, so they appear on the repository page as soon as they're committed.

| File | What it should show |
|------|---------------------|
| `hero.jpg` | The reflection in the windshield at night, shot from the driver's seat, showing a real speed. This is the single most important image in the repository |
| `demo.gif` | A few seconds of the digits changing while accelerating. Keep it under about 5 MB so it loads quickly |
| `bench.jpg` | The circuit on perfboard or a breadboard, showing the transceiver, transistors, and resistors |
| `dash.jpg` | The display sitting on the dashboard, digits facing up, in daylight |

Tips for the hero shot: shoot at dusk or at night, turn off interior lights,
brace the camera on the steering wheel or a small tripod, and use a short
exposure so the digits are not blown out. Multiplexing means each digit is
only lit half the time, so a very fast shutter can catch a digit mid-blank.
If a digit looks missing in the photo, slow the shutter down.

Delete this README once the photos are in.
